# Layout Specifications

## Desktop
```text
Topbar
├── identidad BOVITRACK
├── contexto de finca/usuario
└── cuenta / cierre de sesión

Sidebar
├── Dashboard
├── Animales
├── Fincas
├── Pesajes
├── Vacunaciones
├── Reproducción
├── Leche
├── Usuarios
└── Catálogos

Main Content
└── contenido de la vista
```

## Mobile
- Topbar compacta.
- Navegación lateral como drawer.
- Contenido en una columna.
- Acciones críticas accesibles sin hover.
- Superficies y jerarquía alineadas con Fluent 2.
