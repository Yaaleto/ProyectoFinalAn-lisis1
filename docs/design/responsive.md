# Responsive Guidelines

## Objetivo
La interfaz debe funcionar en computadoras y dispositivos móviles.

## Reglas
- Mobile-first.
- Sidebar como drawer en móvil.
- Formularios de una columna en pantallas pequeñas.
- Controles táctiles con área suficiente.
- No depender de hover para funciones críticas.
- Tablas no deben romper el layout.
- Ficha del animal se reorganiza verticalmente.
- Diálogos no exceden el viewport.
- Mantener jerarquía y espaciado coherentes con Fluent 2.
- Las imágenes ilustrativas no deben romper layout ni desplazar información crítica por debajo del pliegue en móvil.
