# Accessibility Guidelines

## Base
Usar las prácticas de accesibilidad de Fluent 2 como referencia.

## Reglas mínimas
- HTML semántico.
- Labels asociados a inputs.
- Navegación mediante teclado.
- Focus visible.
- No depender solo del color.
- Contraste suficiente.
- Estados disabled y error distinguibles.
- Mensajes comprensibles.
- Iconos decorativos sin ruido para tecnologías asistivas.
- Botones y enlaces con nombres accesibles.
- Estados de carga perceptibles.
- Las imágenes e ilustraciones deben tener texto alternativo cuando aporten contenido; si son decorativas, deben marcarse como tales.

## Formularios
Los errores deben:
1. identificar el campo;
2. explicar el problema;
3. permitir corregirlo sin perder información válida.
