# Design Tokens

## Principio
Los tokens de BOVITRACK deben mapear conceptos de Fluent 2 a nombres semánticos usados por la aplicación.

## Brand
```text
color-brand = #2514EB
color-brand-hover
color-brand-pressed
color-on-brand
```

## Accent / Complementary
```text
color-accent = #C135EB
color-accent-hover
color-accent-pressed
color-on-accent
```

## Danger / Alert
```text
color-danger = #F02C10
color-danger-hover
color-danger-pressed
color-on-danger
```

## Neutrals
```text
color-background
color-surface = #E1E1DD
color-surface-secondary
color-surface-hover
color-border
color-border-strong
color-text = #081A19
color-text-secondary
color-text-disabled
```

## Status
```text
color-success
color-warning
color-info
```

## Spacing
```text
space-xs
space-sm
space-md
space-lg
space-xl
space-2xl
```

## Radius
```text
radius-sm
radius-md
radius-lg
radius-full
```

## Elevation
```text
shadow-2
shadow-4
shadow-8
shadow-16
```

## Typography
```text
text-caption
text-body
text-body-strong
text-subtitle
text-title
text-display
```

## Regla
Los valores concretos deben definirse una vez y consumirse desde componentes. No duplicar valores visuales manualmente.
