# BOVITRACK Design System

## Base
BOVITRACK adopta **Microsoft Fluent 2** como sistema de diseño base.

No se pretende copiar una aplicación de Microsoft. Se utilizan sus principios, tokens y patrones como lenguaje visual consistente, adaptado al dominio ganadero y a la identidad del proyecto.

## Principios
- Claridad.
- Consistencia.
- Jerarquía visual.
- Productividad.
- Baja fricción operativa.
- Legibilidad.
- Accesibilidad.
- Responsive.

## Marca BOVITRACK
Puede personalizar:
- color de marca;
- logotipo;
- nomenclatura;
- componentes específicos del dominio.

## Paleta aprobada
- **Azul primario:** `#2514EB`
- **Rojo de acción/alerta:** `#F02C10`
- **Neutro claro de superficie:** `#E1E1DD`
- **Oscuro profundo / fondo inverso:** `#081A19`
- **Púrpura complementario:** `#C135EB`

## Uso de color
- `#2514EB`: acción primaria y marca.
- `#F02C10`: alerta crítica y acción destructiva.
- `#E1E1DD`: fondos suaves y superficies secundarias.
- `#081A19`: texto fuerte y superficies inversas.
- `#C135EB`: acento complementario.

## Tipografía
Seguir la jerarquía tipográfica de Fluent 2 y definir los tokens concretos durante la implementación.

## Espaciado, radios y elevación
Usar una escala limitada y consistente alineada con Fluent 2.

## Formularios
- Label visible.
- Estados normal, hover, focus, error y disabled.
- Mensaje de validación próximo al campo.
- Acción primaria clara.

## Tablas
- Encabezados claros.
- Acciones consistentes.
- Estado vacío.
- Soporte móvil.

## Iconos
Preferir Fluent System Icons.

## Imágenes e ilustraciones
El sistema puede usar imágenes o ilustraciones de apoyo cuando mejoren la comprensión de acciones, módulos o estados. Se recomiendan especialmente en:
- estados vacíos;
- paneles introductorios;
- confirmaciones o feedback destacados;
- secciones educativas o explicativas.

No deben sustituir etiquetas, títulos o acciones críticas.
