# Technology Stack

## Backend
- PHP
- Symfony

## Persistencia
- Doctrine ORM
- MySQL 8

## Seguridad
- Symfony Security

## Frontend
- Twig
- Symfony Forms
- Symfony UX Twig Components
- Symfony UX Live Components
- Symfony UX Turbo
- Symfony UX Toolkit

## Sistema de diseño
- Microsoft Fluent 2
- Fluent System Icons

## Estilos
- Tailwind CSS como mecanismo de implementación del sistema visual.

## JavaScript
- Stimulus solo para comportamiento puramente del navegador cuando Twig, Live Components o Turbo no resuelvan el caso.

## Restricciones
- No Bootstrap.
- No React/Vue para V1.
- No API frontend separada salvo requerimiento explícito.
- No microservicios.
