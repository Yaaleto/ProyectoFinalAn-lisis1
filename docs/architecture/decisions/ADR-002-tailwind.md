# ADR-002: Tailwind CSS

## Estado
Aceptado.

## Decisión
Usar Tailwind CSS como mecanismo de implementación visual.

## Aclaración
Tailwind no define la identidad visual de BOVITRACK. Microsoft Fluent 2 es el sistema de diseño base.

## Restricciones
- No Bootstrap.
- Priorizar tokens semánticos.
- Evitar colores arbitrarios por pantalla.
- Los componentes reutilizables encapsulan estilos repetidos.
