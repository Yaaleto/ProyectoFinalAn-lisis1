# ADR-003: Symfony UX

## Estado
Aceptado.

## Decisión
Usar:
- Twig Components para UI reutilizable.
- Live Components para interacción con servidor.
- Turbo para navegación/actualización parcial.
- Stimulus para comportamiento local.
- UX Toolkit para apoyar la construcción de componentes propios.

## Regla
No introducir una solución JavaScript más compleja si Symfony UX cubre adecuadamente el caso.
