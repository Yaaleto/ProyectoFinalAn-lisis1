# Project Overview

## Producto
**BOVITRACK** es un sistema web de gestión ganadera orientado a organizaciones que administran una o varias fincas.

## Objetivo
Centralizar y relacionar la información de fincas, usuarios, animales y registros operativos, manteniendo segregación de datos entre organizaciones y control de acceso por rol y finca.

## Actores
- **Administrador:** administra usuarios, fincas, asignaciones, catálogos, animales y consultas de su organización.
- **Encargado de finca:** opera únicamente sobre su finca activa asignada y sobre los animales autorizados de dicha finca.

## Áreas funcionales del MVP
- Autenticación y control de acceso.
- Usuarios, fincas y asignaciones.
- Catálogos de razas y vacunas.
- Gestión de animales.
- Nacimientos y procedencia.
- Pesajes.
- Vacunaciones.
- Reproducción básica.
- Producción de leche.
- Historial integral y genealogía.

## Principio de trabajo
El alcance V1/MVP queda congelado. Toda ampliación debe evaluarse antes de incorporarse.
