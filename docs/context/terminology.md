# Terminology

| Término | Definición |
|---|---|
| BOVITRACK | Sistema web de gestión y seguimiento ganadero. |
| Organización ganadera | Propietario lógico de la información y límite de segregación. |
| Administrador | Usuario con permisos administrativos dentro de su organización. |
| Encargado de finca | Usuario operativo limitado a una finca activa. |
| Finca | Unidad productiva perteneciente a una organización. |
| Animal | Ejemplar bovino identificado individualmente en el sistema. |
| Arete | Identificador del animal, único dentro de la organización. |
| Código interno | Identificador global único generado por el sistema. |
| Historial animal | Conjunto de registros asociados al animal. |
| Genealogía | Ascendencia derivada de padre y madre registrados. |
| Monta reproductiva | Registro básico de relación reproductiva. |
| Producción de leche | Cantidad registrada para una hembra productora. |
| Fluent 2 | Sistema de diseño base adoptado por BOVITRACK. |
| V1/MVP | Primera versión funcional limitada al alcance definido. |
