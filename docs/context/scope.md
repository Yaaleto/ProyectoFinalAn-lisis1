# Scope

## Dentro del alcance V1/MVP
1. Inicio y cierre de sesión.
2. Autorización por rol, organización y finca.
3. Administración de usuarios y fincas.
4. Asignación de un Encargado a una única finca activa.
5. Catálogos de razas y vacunas.
6. Registro, consulta y modificación de animales.
7. Registro de nacimientos y animales externos.
8. Pesajes.
9. Vacunaciones.
10. Montas reproductivas básicas.
11. Producción de leche con múltiples registros por día.
12. Historial integral del animal.
13. Genealogía disponible hasta tres generaciones.
14. Interfaz responsive.

## Fuera del alcance inicial
- Aplicación móvil nativa.
- Modo offline.
- React, Vue u otro frontend SPA separado.
- API pública como producto independiente.
- Microservicios.
- Analítica avanzada.
- Dashboards sofisticados.
- Notificaciones complejas.
- Módulos nuevos no contemplados por el DERCAS.

## Regla
Si una funcionalidad no contribuye directamente al cumplimiento de RF-01 a RF-10, no debe priorizarse antes de completar el MVP.
