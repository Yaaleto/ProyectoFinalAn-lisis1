# Functional Requirements

| RF | Nombre | Prioridad | Resumen |
|---|---|---:|---|
| RF-01 | Autenticación y control de acceso | Alta | Inicio/cierre de sesión y autorización. |
| RF-02 | Administración de usuarios y fincas | Alta | Gestión de usuarios, fincas y asignaciones. |
| RF-03 | Gestión de catálogos básicos | Media | Razas y vacunas. |
| RF-04 | Gestión de animales | Alta | Registrar, consultar y modificar animales. |
| RF-05 | Nacimientos y genealogía | Alta | Nacimientos, procedencia y progenitores. |
| RF-06 | Seguimiento de pesajes | Alta | Registrar, consultar y modificar pesajes. |
| RF-07 | Gestión de vacunaciones | Alta | Registrar, consultar y modificar vacunaciones. |
| RF-08 | Registro de monta reproductiva | Media | Montas reproductivas básicas. |
| RF-09 | Producción de leche | Media | Múltiples registros y total diario. |
| RF-10 | Consulta integral del animal | Alta | Ficha, historial y genealogía. |
